Кроссплатформенное мобильное приложение для управления личными финансами с интеллектуальным прогнозированием расходов на основе машинного обучения.

Особенности:
Учет финансов
Учет доходов и расходов по категориям
Управление несколькими счетами
Переводы между счетами
Накопительные цели с отслеживанием прогресса
Лимиты по категориям с цветовой индикацией
ML-прогнозирование
Прогноз расходов на следующий месяц на основе линейной регрессии
Оценка точности через метрики R², MAE и Confidence
Адаптивное обучение на истории последних 6 месяцев
Сглаживание данных методом скользящего среднего
Локальная обработка — все вычисления на устройстве, без передачи данных

Визуализация:
Круговые диаграммы распределения расходов/доходов
Столбчатые графики динамики с фильтрацией (неделя/месяц/год)
Линейные графики с прогнозной точкой
Интерактивные элементы и адаптивная сетка
Автоматизация
Сканирование кассовых чеков (OCR через Google ML Kit)
Экспорт отчетов в PDF с кириллическими шрифтами
Ежедневные push-уведомления
Чат с интеллектуальными рекомендациями

Быстрый старт

Требования
Flutter 3.0 или выше
Dart 2.17 или выше
Android SDK 29+ (Android 10+)
iOS 14.0+

Установка

Клонируйте репозиторий
git clone https://github.com/yourusername/finance-tracker.git
cd finance-tracker

Установите зависимости
flutter pub get

Запустите приложение
flutter run

Зависимости
Основные пакеты, используемые в проекте:
dependencies:
  flutter:
    sdk: flutter
  fl_chart: ^0.65.0          # Визуализация графиков
  google_mlkit_text_recognition: ^0.11.0  # OCR для сканирования чеков
  pdf: ^3.10.0               # Генерация PDF-отчетов
  flutter_local_notifications: ^16.0.0    # Push-уведомления
  shared_preferences: ^2.2.0  # Локальное хранение настроек
  sqflite: ^2.3.0            # Локальная база данных SQLite
  path_provider: ^2.1.0      # Работа с файловой системой

Ключевые компоненты:
AnalyticsService — сервис аналитики и прогнозирования
LinearRegression — реализация ML-модели на чистом Dart
DBHelper — работа с базой данных SQLite
NotificationService — управление push-уведомлениями
MLService — интерфейс для взаимодействия с ML-моделью

Конфигурация

База данных
Приложение использует SQLite с таблицами:
accounts — счета
transactions — транзакции
categories — категории
limits — лимиты по категориям
goals — накопительные цели

Настройки
Хранятся в SharedPreferences:
Выбранная тема (темная/светлая)
Время ежедневных уведомлений
Предпочтения по визуализации

Поддерживаемые платформы
Android 10+ (API 29)
iOS 14.0+

Поддержка портретной и ландшафтной ориентации
